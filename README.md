# 🎂 Online Doğum Günü Davetiyesi

Kişiye özel, animasyonlu tek sayfalık davetiye. Tüm bilgiler **`config.js`** içinde.

- Canlı geri sayım, konfeti, yükselen balonlar, üflenebilir mumlar
- Haritada aç / Takvime ekle / WhatsApp ile yanıtla düğmeleri
- Telefon ve masaüstü uyumlu

## Düzenleme
1. `config.js` dosyasını aç, tarih/isim/mekan bilgilerini değiştir.
2. Fotoğrafı değiştirmek için `assets/foto.jpg` dosyasının üzerine yenisini yükle.
3. Detaylar için `Duzenleme-Rehberi.pdf`.

## Yayınlama (GitHub Pages)
Settings → Pages → Branch: `main` / `/ (root)` → Save.
